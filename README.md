# I am Leon 👋

## Currently working on

- **[SurfaceRT-GPU-Driver](https://github.com/LBSiUK/SurfaceRT-GPU-Driver)**: hardware-accelerated OpenGL ES on a 2012 Microsoft Surface RT (NVIDIA Tegra 3) running postmarketOS. I debugged the open-source grate Mesa driver and X stack until es2gears ran at about 60 fps on the GPU instead of the CPU.
- **[DiskMap](https://github.com/LBSiUK/DiskMap)**: a native SwiftUI disk usage visualiser for macOS, with a parallel scanner that maps a whole drive in under half a minute and a self-updater that installs new releases from GitHub.
- **[Tracqer](https://github.com/LBSiUK/tracqer)**: a record collection tracker with a FastAPI and PostgreSQL backend (encrypted API responses), a React dashboard, a SwiftUI iOS app and an Objective-C client for iOS 6.
- **[Suds & Slots](https://github.com/LBSiUK/sudsandslots)**: an iPad app for booking the washer, dryer and drying rack in a shared house, backed by a small FastAPI service.
- **[Flamenco Farm Monitor](https://github.com/LBSiUK/flamenco-farm-monitor)**: a live dashboard for my Blender render farm, showing temperatures, CPU, GPU and memory use and frame progress for every machine.
